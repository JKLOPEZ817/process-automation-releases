# MTC MoveMint — public releases

This repository contains public, versioned Windows releases for MTC MoveMint, formerly PROCESS AUTOMATION.

- Preserve existing release tags and assets.
- Never replace an existing version's executable.
- Each release must include `PROCESS_AUTOMATION.exe`, release notes, and a verified SHA-256 digest.
- Publish new versions under a new tag such as `v1.1.4`.
- Do not put source secrets, signing private keys, API tokens, customer records, or local working files in this public repository.

See [v1.1.4 release notes](v1.1.4/RELEASE_NOTES.md). The v1.1.4 checksum file in this repository matches the executable attached to the public v1.1.4 GitHub Release (GitHub asset digest verified: `sha256:7e673b5454732f6ef5bde21d104d17f9fbd8ecaacffad8d68adf01d38ea5a973`, 30,324,999 bytes).

Executables are distributed only as GitHub Release assets; none are committed to this repository.
