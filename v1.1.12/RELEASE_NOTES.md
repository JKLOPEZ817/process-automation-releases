## MTC MoveMint v1.1.12

- Tally Report prompts for an inclusive SYSPRO order-date range. Press Enter at the first prompt to use the working date and at the second prompt to use the start date.
- The report saves in the current working-date folder, including on days without a pick list.
- The Orders sheet keeps existing rows and appends stock lines for newly found sales orders. A matching pick list or CM report supplies the S.O. Value.
- Download MTC_MoveMint.exe for manual installation. PROCESS_AUTOMATION.exe is also provided for compatibility with existing update clients.

The Windows executable passed an offline startup check. The Tally Report update was tested with simulated SYSPRO data. Live SYSPRO and the signed-update flow were not tested.
