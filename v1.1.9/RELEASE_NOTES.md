## MTC MoveMint v1.1.9

The updater displays short codes for its status.

- `U002` — The verified update is ready to install.
- `U003` — Update installation started.
- `U001` — Update completed.
- `U004` — Update rollback failed.

The license codes remain `L001` for expiration and `L002` for revoked access. This release uses the native Windows packaging introduced in v1.1.8.
