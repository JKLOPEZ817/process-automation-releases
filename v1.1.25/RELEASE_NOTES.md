## MTC MoveMint v1.1.25

- Press **R** on the Requested Ship Date results screen to reload the S.O. list with the same dates, DMS filters, and connection.
- After saving the Tally Report, press **R** to update the same workbook. If you chose all matching orders, refresh uses the current matches. If you pasted specific S.O. IDs, refresh uses the selected orders that still match.
- Download `MTC_MoveMint.exe` for manual installation. `PROCESS_AUTOMATION.exe` is the compatibility asset for existing update clients.

Verified with 27 tests, a synthetic Excel workbook refresh, and an offline startup check. Live SYSPRO and signed auto-update remain unverified.
