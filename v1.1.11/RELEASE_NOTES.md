## MTC MoveMint v1.1.11

- After a normal exit, an updated legacy installation renames its executable from PROCESS_AUTOMATION.exe to MTC_MoveMint.exe when its rollback backup has cleared.
- An existing MTC_MoveMint.exe in the same folder is preserved.
- Open MTC_MoveMint.exe on subsequent launches. Shortcuts to the previous filename need to point to the new name.
